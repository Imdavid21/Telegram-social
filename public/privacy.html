Privacy

What Supergram sees, stores, and leaves alone.

Effective August 27, 2026. Supergram is an independent third-party client that uses the Telegram API. It is not affiliated with or endorsed by Telegram.

The short versionSupergram reads data available to the Telegram account you authorize. It does not maintain a centralized database containing your Telegram message history. OpenAI summaries are optional and use an API key you provide.

What Supergram processes

  • Your Telegram phone number, verification code, and two-step-verification password are transmitted only as needed to complete Telegram authentication. Verification codes and passwords are not intentionally stored.
  • After successful authentication, Telegram session data is encrypted server-side and returned to your browser in an HttpOnly, Secure cookie.
  • Conversation, group, channel, bot, and message metadata, posts, reactions, view counts, replies metadata, media, and official sponsored messages are fetched from Telegram on demand for your authorized account.
  • Read and saved UI state, theme preferences, feed preferences, and non-secret summary preferences may be stored locally in your browser.

Summaries and OpenAI

Local summaries are generated in the browser and are not sent to a model provider. If you choose OpenAI summaries, you must provide your own OpenAI API key. The key is held only in the current page's memory, is not written to localStorage or sessionStorage, and is not sent to the Supergram backend. Refreshing or closing the page clears it.

When OpenAI summaries are enabled, eligible Telegram text is sent directly from your browser to OpenAI using your API account. Private-chat summarization is disabled by default and private-chat text is sent only if you explicitly enable that setting. Supergram requests store: false; OpenAI's own API terms and data-handling policies still apply to requests made to OpenAI.

What is not intentionally stored

The service does not maintain a centralized database of your Telegram messages. Telegram verification codes, two-step-verification passwords, API hashes, raw Telegram session strings, and your OpenAI API key are not stored in browser localStorage.

Private conversations

Private chats shown in your Supergram feed remain tied to your authenticated Telegram session. They are not published, indexed for other users, or used as public discovery content by Supergram. Optional OpenAI summarization is the exception described above.

Service providers

The web application may be delivered through Vercel, the persistent application backend through Railway, and Telegram provides messaging and API infrastructure. If you enable OpenAI summaries, OpenAI also processes the text sent for those summaries. Those providers process data according to their own terms and policies.

Retention

Temporary login flows expire after approximately 10 minutes. Idle in-memory Telegram client connections are recycled after approximately 30 minutes. The encrypted browser session cookie is configured for up to 30 days unless you disconnect or clear browser data. Local browser preferences remain until you remove them. The OpenAI API key is cleared on page refresh or close.

Security

Production traffic uses HTTPS. Telegram application credentials remain on the persistent backend. Session material is encrypted using authenticated encryption before it is placed in the HttpOnly cookie. User-provided OpenAI keys are kept out of persistent browser storage, but any secret used in a web page can still be exposed if that page or a browser extension is compromised.

Your controls

You can disable OpenAI summaries or remove the in-memory key at any time. You can disconnect from Telegram in Supergram to remove its session cookies, clear browser site data to remove local UI state, and revoke sessions from Telegram's own Devices settings.
